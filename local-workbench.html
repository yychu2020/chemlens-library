返回公开文献库

在自己的电脑上，整理文献并导入公众号

公开阅读无需 ChatGPT 登录。本机工作台把文献编辑、备份、公众号设置和草稿导入放在这台电脑运行，直接从本机网络连接微信。

首次安装

  1. 安装 Node.js 22 或更新的 LTS 版本。
  2. 下载完整工作台 ZIP，解压到硬盘文件夹。
  3. 双击 Start-ChemLens.cmd，首次会安装依赖，然后打开本机网页。使用期间保持程序运行。
  4. 在本机网页右上角「本机设置」绑定原站备份，再从「本地同步与备份」恢复资料；随后在「公众号设置」重新关联公众号。

原站私人上传和笔记不在公开 ZIP 中。请在仍可访问原站时，先导出完整备份。已有公开库里的 21 篇文献与原图可直接阅读。

已经启动

打开本机工作台打开本机设置

公众号白名单填写本机请求微信时的公网出口 IP。若网络出口固定，可保持这个地址稳定；无需沿用原站云端 IP。

GitHub Pages 本身不能保管密钥或运行导出服务。即使当前网络打不开 GitHub Pages，已解压的本机工作台仍可启动；微信接口和模型服务各自需要网络可达。GitHub 域名的国内可达性不能保证。
