迁入原站资料

先在原站「本地同步与备份」下载完整备份。在本机尚未保存资料前，选择其中的 manifest.json 绑定原账号标识，然后返回工作台的「本地同步与备份」恢复整个备份。

只读 manifest.json 的账号标识，不上传这个文件。绑定不会自动读取原站云端，也不会导入公众号密钥。

模型服务（按需配置）

阅读、编辑和公众号导出无需模型密钥。新文献自动解读、高分筛选需自行配置模型服务，并使用服务商的独立 API 额度。

公众号与保存位置

返回工作台「公众号设置」，重新填写 AppID 和 AppSecret 并测试连接。微信白名单应填写这台电脑访问微信接口时的公网出口 IP；电脑的内网地址不能代替它。

PDF和服务端记录保存在本机目录：。标签、收藏等还使用本机浏览器存储，请通过“本地同步与备份”同时保存两部分，并备份这个资料目录。公众号配置加密保存，解密密钥由本机用户目录管理；模型 API 密钥属于本机配置，不上传到 GitHub。

每日筛选和后台处理需要本机程序保持运行。保存研究方向并开启每日筛选后，本机服务在北京时间09:00后接续当天任务；关闭电脑时不会运行。原站的云端定时任务不会迁到 GitHub Pages。
