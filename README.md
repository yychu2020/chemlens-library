公开入口：https://yychu2020.github.io/chemlens-library/

本机工作台安装入口：https://yychu2020.github.io/chemlens-library/local-workbench.html

公开库包含原有 21 篇文献、119 张主图及中文解读、计算方法、科学问题、色卡和 PDF；阅读不依赖 ChatGPT 登录。本次同步的是新版功能代码和已公开资料，不包含原站私人上传、私人笔记、公众号密钥、模型密钥或用量回执。

## Windows 使用本机工作台

1. 安装 Node.js 22 或更新的 LTS 版本。
2. 下载本仓库 ZIP 并解压到硬盘，双击 `Start-ChemLens.cmd`。首次安装依赖需要网络，依赖地址固定为官方 npm registry。
3. 程序打开本机设置。若要迁入原站私库，先在原站「本地同步与备份」导出完整备份，再在本机设置选择 `manifest.json` 绑定备份的账号标识。此步骤应在上传、编辑或关联公众号之前完成。
4. 返回本机工作台的「本地同步与备份」，选择完整备份文件夹或 ZIP，校验并确认恢复。公众号密钥不在备份里，需在本机「公众号设置」重新填写。
5. 将这台电脑请求微信时的公网出口 IP 加入公众号 API IP 白名单。在公众号设置测试连接，然后从文献导出页导入草稿箱。

程序启动后地址为 `http://127.0.0.1:4188/`。使用期间需保持启动窗口运行；关闭窗口会停止服务。也可在仓库根目录执行 `npm start`，首次需先在 `local` 目录执行 `npm ci --omit=dev --ignore-scripts`。

## 功能与数据

- 本机端使用当前版界面和接口：文献上传与编辑、标签、手动图片勘误与移除、发表日期排序、下载 PDF、备份恢复、多公众号配置和带行内排版的草稿导入。
- 新文献自动解读、题录评分、OA 自动入库与解读依赖模型服务。在「本机设置」配置自己的智谱或 OpenAI API 密钥及模型；独立 API 额度与 ChatGPT 会员无关。
- 保存研究方向并开启每日筛选后，本机程序在北京时间 09:00 后接续当天任务。电脑和本机程序都需保持运行；原站的云端定时任务没有迁移到 GitHub Pages。
- PDF 与服务端记录默认保存在当前 Windows 用户的 `%LOCALAPPDATA%\ChemLens`，标签、收藏等浏览器工作区记录也使用本机浏览器存储。完整保存两部分请使用「本地同步与备份」。资料不保存在 GitHub 仓库。可通过环境变量 `CHEMLENS_LOCAL_DATA` 指定另一个资料目录。更新时替换程序文件，不删除资料目录。
- 公众号配置加密存储；本机配置文件包含解密密钥和模型配置，请像其他本机私人资料一样保护并备份整个目录。模型 API 密钥保存在本机配置，接口不会把它返回浏览器。
- 原站私库不会自动同步本机。使用完整备份手动迁入或迁出；已存在的同 ID 资料默认保留，需明确选择才覆盖。不同电脑各有独立资料，除非手动恢复同一份备份。

## 部署边界

GitHub Pages 只提供静态页面，不运行 Node 服务，也不存放私人密钥。公众号调用由本机服务发起，因此使用本机网络的公网出口；内网 IP 固定不代表公网出口一定固定。

不保证所有国内线路都能稳定访问 GitHub Pages。已下载的本机工作台可直接启动，无需访问 ChatGPT；微信、期刊数据源和模型接口仍各自需要网络可达。

本机服务仅监听回环地址，检查 Host、Origin、同站会话及备份账号。它是单机私人工作台，不用于直接开放公网或部署为多用户服务器。云端管理员审批和 ChatGPT 账号体系保留在原站，不会因为本机服务而被绕过。
